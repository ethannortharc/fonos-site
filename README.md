# fonos-site

Static pages for **Fonos for iPhone**, served by GitHub Pages at <https://fonos.giomni.com>:
the privacy policy (`/privacy`) and the support page (`/support`) that App Store Connect and the
app itself link to, in English and Simplified Chinese.

The source of truth is `release/app-store/legal/site/` in
[fonos-ios](https://github.com/ethannortharc/fonos-ios); this repository only publishes a copy.
Edit the pages there, then copy them here and push.
