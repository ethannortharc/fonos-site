Fonos 支持

Fonos 是一款 iPhone 语音听写 App。点一下开始录音，说话，就能得到可以插入、复制、润色、翻译或归入笔记本的文字——可以在 App 内完成，也可以用 Fonos 键盘在你正在打字的那个 App 里直接完成，不用跳转。

快速开始

  1. 打开 Fonos，在系统提示时允许麦克风权限。
  2. 在系统提示时允许语音识别权限。Apple Speech 无需任何额外设置，也不需要 API key。
  3. 在 Dictate 标签页点击麦克风，说话，再点一下停止。
  4. 可选——若要在其它 App 里输入，请在 iOS 设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → Fonos 中添加 Fonos 键盘，然后为听写打开「允许完全访问」（Allow Full Access）。
  5. 可选——若要使用你自己的语音转写或语言模型服务，在 Settings → Models 中添加。

卡住了？Settings → General → Setup Doctor 会一次性检查权限、键盘桥接、endpoint 和配置。

常见问题

Fonos 为什么需要麦克风？

用于录制你的语音以进行听写。在你开始一次录音之前，或在你显式启动键盘听写的 Keyboard Ready 会话之前，不会录任何东西。如果你之前拒绝了该权限，可在 iOS 设置 → 隐私与安全性 → 麦克风 → Fonos 中重新打开。

Fonos 为什么需要语音识别权限？

Apple Speech 是默认的转写引擎，识别由 iOS 执行。iOS 要求 App 在使用它之前获得你的授权。当你的设备和所选语言支持本机识别时，音频在设备上完成识别；否则 iOS 可能把它发送到 Apple 的服务器，该过程受 Apple 的隐私政策约束。如果你改为配置自己的语音转写服务，则使用该服务，不再使用 Apple Speech。

Full Access 是什么？Fonos 键盘为什么要它？

Full Access 是 iOS 上允许自定义键盘与其所属 App 和网络通信的开关。iOS 自定义键盘不能自己录音，因此 Fonos 键盘请求主 App 代它录音和转写，通过设备上的共享 App Group 容器通信。这条通道只有在打开 Full Access 时才可用。

没有 Full Access，Fonos 键盘仍然可以打字：数字、标点、空格、删除、回车，以及切回你常用键盘的地球键。只有听写需要 Full Access。

打开位置：iOS 设置 → 通用 → 键盘 → 键盘 → Fonos → 允许完全访问。

Keyboard Ready 是什么？为什么会看到橙色小点？

Keyboard Ready 是一个限时窗口，在此期间主 App 保持麦克风输入处于活动状态，好让键盘不跳转 App 就能听写。在 Fonos → Settings → General → Keyboard Dictation 中启动。默认 15 分钟，可设置为 1 到 30 分钟。

会话活动期间，iOS 会显示橙色麦克风指示——那是 iOS 在如实告诉你：有一个输入会话开着。Fonos 会丢弃全部空闲音频，在你点击 Fonos 键盘上的麦克风之前不保留任何内容。Fonos 内有一个横幅显示剩余时间，一点即可停止会话；它也会自动过期。仅仅启动 Fonos 从不打开麦克风。

键盘听写要求 Fonos App 在运行吗？

是。键盘自身没有录音器，所以主 App 必须存活并处于 Keyboard Ready 会话中。让 Fonos 待在后台就够了——不需要它在前台显示。如果你在 App 切换器里划掉了 Fonos，或 iOS 在它处于后台时回收了它，键盘会提示无法连接到 App；重新打开 Fonos 并再次启动 Keyboard Ready 即可。

没有 Full Access 时键盘能做什么？

可以输入数字、标点、空格、删除和回车，并用地球键切换到下一个键盘。不能听写，因为听写需要与主 App 的连接。键盘会明确显示缺什么，而不是无声失败。

Fonos 为什么请求本地网络权限？

只有当你把 Fonos 指向你自己网络中的模型服务器时才会请求——例如地址形如 http://192.168.1.10:11434 的 OMLX、Ollama 或 LM Studio。iOS 要求 App 在访问本地网络上的其它设备前获得授权。如果你只用 Apple Speech 或互联网上的 HTTPS 服务，这个提示不会出现。该权限按 App 管理，位置在 iOS 设置 → 隐私与安全性 → 本地网络。

如何删除我的数据，或撤回给 AI 服务的授权？

所有数据都在你的设备上。

  • 历史记录：在 History 标签页左滑一条记录即可删除。Settings → General → History 设置记录保留多久（7 天、30 天、90 天或永久）。
  • 笔记：在笔记本内左滑删除单条笔记；整个笔记本可在该笔记本的设置里删除。
  • API key：在 Settings → Models 里删除对应的模型配置，它的 key 会随之从 Keychain 中删除。如果你想彻底清除凭据，请在卸载前先做这一步。
  • 远端 AI 授权：Settings → General → Privacy & Data Sharing → 撤回。撤回后 Fonos 会阻断后续的网络语音转写与语言模型请求，直到你再次允许该 endpoint。

撤回授权不会删除服务商此前已经收到的内容——请直接依据该服务商自己的隐私政策向它提出请求。

如何完全离线使用 Fonos？

使用 Apple Speech，让所有 recipe 都不含语言模型步骤，并且不配置任何远端 endpoint。这样 Fonos 自身不会向网络发送任何内容。

Apple 在设备上识别还是在 Apple 的服务器上识别，由 iOS 根据你的设备和所选语言决定；当该语言在你的设备上受支持并已下载时，iOS 使用本机识别。最诚实的验证方法是飞行模式：如果断网后听写仍然出文字，说明识别发生在设备上。

键盘听写故障排查

如果点击键盘上的麦克风没有反应或报错，按顺序检查：

  1. Fonos 键盘是否已添加？「允许完全访问」是否已打开？（iOS 设置 → 通用 → 键盘 → 键盘 → Fonos）
  2. Fonos 是否在运行？Keyboard Ready 是否处于活动状态？（横幅会显示剩余时间）
  3. 会话是否已过期？重新启动即可，默认时长 15 分钟。
  4. 是否被来电、Siri 或耳机切换打断？Fonos 会暂停并恢复；如果横幅显示已暂停，稍等片刻，或停止后重新启动会话。
  5. 仍未解决：Settings → General → Setup Doctor，它会报告权限、App Group 桥接和 endpoint 可达性。

模型配置

Fonos 开箱即用 Apple Speech，不需要账号，也不需要 API key。

在 Settings → Models 中，你可以填写 endpoint 和自己的 API key，添加你自己的语音转写或语言模型服务——任何兼容 OpenAI 的服务，或本地服务器都可以。在向已配置的 endpoint 发送语音或文本之前，Fonos 会标明服务商和目标地址、说明将发送什么，并请求授权。该授权可以随时撤回。

公网 endpoint 必须使用 HTTPS。只有你自己配置的 localhost 或局域网地址才接受明文 HTTP。

API key 保存在 iOS Keychain 中，并标记为仅限本设备。它们绝不会发送给 Fonos 的开发者。
